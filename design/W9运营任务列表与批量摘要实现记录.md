# W9 运营任务列表与批量摘要实现记录

## 1. 目标

为运营首页提供可直接使用的任务清单。运营人员无需逐条进入任务详情，即可看到企业、任务状态、风险分、证据处理进度、人工确认状态、最新报告和建议下一步操作。

## 2. 接口

```http
GET /api/tasks
```

支持以下查询参数：

| 参数 | 含义 | 约束 |
|---|---|---|
| `query` | 匹配任务编号、企业查询词或原始指令 | 可选，最多 256 字符，不区分大小写 |
| `status` | 任务状态 | 可重复传入多个值 |
| `operator_id` | 任务所属运营人员 | 可选，精确匹配，最多 64 字符 |
| `page_size` | 每页条数 | 默认 20，范围 1～100 |
| `cursor` | 上一页返回的不透明游标 | 可选，不允许前端自行拼接 |

示例：

```http
GET /api/tasks?operator_id=operator-1&status=WAITING_OPERATOR_CONFIRMATION&status=REPORT_FAILED&page_size=20
```

## 3. 排序与分页

任务固定按以下顺序排列：

```text
updated_at DESC, task_id DESC
```

分页采用键集游标，不使用 offset。游标绑定上一页末条任务的 `updated_at` 和 `task_id`，在任务量增加时仍能避免深分页扫描和同一页内的重复项。

响应字段：

- `items`：当前页任务；
- `has_more`：是否仍有下一页；
- `next_cursor`：存在下一页时返回；
- `page_size`：本次请求采用的页大小。

接口不返回总数。运营首页需要总量时，应另建按状态聚合的轻量统计接口，避免列表查询每次执行全表计数。

## 4. 单条任务摘要

每条 `items` 包含：

- `task`：完整任务基础信息；
- `company_name`：优先使用冻结数据快照中的规范企业名，尚未形成快照时回退到任务查询词；
- `risk`：最新评分快照的原始分、人工分、原始等级、人工等级和计算时间；
- `evidence_progress`：证据总数、确认数、驳回数、未处理数、正文抓取成功/失败数和风险类型分布；
- `confirmation_state`：`NOT_READY`、`PENDING`、`VALID` 或 `STALE`；
- `readiness_blockers`：当前阻塞原因；
- `next_action`：前端应突出显示的下一步动作；
- `latest_confirmation`：最近一次运营确认摘要；
- `latest_report`：最新报告版本摘要。

列表与单任务 `/workspace` 复用同一套就绪度、确认有效性和下一步动作规则，避免两个页面对同一任务显示不同结论。

## 5. 数据访问设计

列表先查询一页任务 ID，再对这一页执行固定数量的批量查询：

1. 最新企业数据快照；
2. 最新评分快照；
3. 人工改分记录；
4. 公开证据；
5. 证据正文快照；
6. 最新运营确认；
7. 最新报告版本。

最新版本查询使用 `ROW_NUMBER() OVER (PARTITION BY task_id ...)`，每类数据一次查询返回整页结果。应用层按 `task_id` 聚合并重建运营确认哈希。因此数据库查询次数不随每页任务条数线性增加，没有逐任务 N+1 查询。

## 6. 确认状态判定

列表没有使用简化时间戳推断。`VALID` 与 `STALE` 仍按 W7 的完整确认输入计算：

- 最新企业数据快照及内容哈希；
- 最新评分快照、原始分、人工分和等级；
- 全部人工调整记录；
- 全部证据的确认/驳回状态与内容哈希；
- 每条证据最新成功正文快照。

这保证了首页的“已确认”可直接作为报告生成入口的可信提示，但真正生成报告时仍由服务端门禁再次校验。

## 7. 错误语义

- 无效游标、页大小越界、查询词或操作人过长：`400 INVALID_TASK_LIST_QUERY`；
- 不合法的任务状态枚举：`400 INVALID_REQUEST`；
- 查询结果为空：返回 `200`、空 `items`、`has_more=false`。

## 8. 自动化验证

已覆盖：

- 运营人员与状态筛选；
- 模糊查询；
- 两页游标分页无重复、无遗漏；
- 空结果；
- 无效游标和页大小越界；
- 完整报告流程结束后，列表中的原始分、人工分、证据进度、确认状态、报告摘要和 `DOWNLOAD_REPORT` 动作正确；
- OpenAPI 文档可解析。

## 9. 当前边界

- 当前查询仅覆盖任务编号、企业查询词和原始指令，尚未引入独立企业档案的别名搜索；
- 暂未提供创建时间区间、更新时间区间和风险等级筛选；
- 暂未提供状态数量看板；
- 列表接口返回的是工作流摘要，大体量证据正文和报告内容仍按需进入任务工作台加载。
