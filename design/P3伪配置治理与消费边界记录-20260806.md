# P3 伪配置治理与消费边界记录

日期：2026-08-06  
范围：规则、Skills、数据源/搜索/模型连接器、DOCX 模板管理。

## 1. 判定原则

页面字段只有满足以下至少一项才保留为可编辑项：

1. 新任务会冻结该字段，执行器在运行时读取并改变行为；
2. 发布门禁会读取该字段并产生明确的允许/拒绝结果；
3. 该页面明确定位为“连接测试档案”，字段只用于测试或预览，并且禁止发布和进入任务快照。

只用于说明、没有执行器或门禁消费证据的字段，不再作为可编辑配置展示。

## 3. 后台强制约束

- 连接器类别不再接受旧式通用 JSON 通过校验或发布；
- DATA_SOURCE 和 MODEL 即使连接测试通过，也不能发布；
- 新任务快照只包含当前有运行消费者的 `RULES`、`SEARCH`、`SKILL`、`REPORT_TEMPLATE`；
- SEARCH 的失败策略由“必查/可选”派生，不能形成矛盾组合；
- Skill 只允许调整启停和发布依赖，其余字段必须与内置执行器声明完全一致；
- 规则区间固定为 8/6/4/2，风险标签必须为空，权重键必须与 V1 引擎实际读取集合完全一致；
- 模板发布前逐项检查运行定位词是否真实存在于 `word/document.xml`。
