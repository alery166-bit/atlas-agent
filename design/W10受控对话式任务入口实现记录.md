# W10 受控对话式任务入口实现记录

## 1. 目标

为对话页面提供首个可调用的后端入口，使运营人员可以直接输入自然语言：

- 创建单企业旧风险报告更新任务；
- 查询指定任务或某企业最近任务的当前状态；
- 得到缺失输入提示；
- 得到与当前任务状态一致的下一步操作。

W10 不把聊天文本直接变成证据确认、人工改分或正式报告生成命令。高影响操作仍通过现有结构化接口和服务端门禁执行。

## 2. 接口

```http
POST /api/agent/messages
Idempotency-Key: agent-message-001
X-Operator-Id: operator-1
Content-Type: application/json
```

创建任务：

```json
{
  "message": "调查北京童程童慧科技有限公司近一年的经营状况，重点核实失联、拖欠工资和门店关闭。",
  "previous_report_file_id": "report-v1"
}
```

查询任务：

```json
{
  "message": "这个任务进度怎么样了？",
  "task_id": "00000000-0000-0000-0000-000000000001"
}
```

也可以在消息中直接提供任务编号、任务 UUID、完整企业名称或统一社会信用代码。

## 3. 当前支持的意图

| 意图 | 行为 |
|---|---|
| `CREATE_RISK_REPORT_TASK` | 校验企业锚点和原报告，幂等创建风险报告更新任务 |
| `QUERY_TASK_STATUS` | 查询指定任务，或当前操作人名下匹配企业/任务编号的最近任务 |
| `UNSUPPORTED_SCOPE` | 明确拒绝尚未开放的招商线索任务，不创建任务 |
| `UNKNOWN` | 不猜测任务，返回缺失输入 |

当前企业锚点支持：

- 18 位统一社会信用代码；
- 以法定组织形式结尾的完整企业名称；
- 常见有限公司、股份有限公司、集团有限公司、合伙企业、律师事务所、分公司等形式。

## 4. 响应模型

响应包含：

- `message_id`：本次响应标识；
- `type`：`TASK_CREATED`、`TASK_STATUS`、`NEEDS_INPUT` 或 `UNSUPPORTED_SCOPE`；
- `assistant_message`：可直接显示在对话气泡中的运营提示；
- `parsed_intent`：确定性解析结果；
- `company_query`：识别出的企业锚点；
- `workspace`：存在任务时返回 W8 单任务工作台聚合状态；
- `required_inputs`：需要补充的字段；
- `suggested_actions`：下一步操作代码、显示文案、HTTP 方法和端点。

建议操作来自现有 `next_action`，不会在 Agent 模块内重新推导一套状态机。

## 5. 安全与确定性边界

第一版使用本地确定性解析器，不依赖外部模型：

1. 完整企业名称和统一社会信用代码使用受控规则提取；
2. 任务编号和任务 UUID 使用严格格式识别；
3. 任务创建复用现有 `Idempotency-Key`；
4. 任务查询受 `X-Operator-Id` 范围约束；
5. 缺少原报告时返回 `PREVIOUS_REPORT_FILE_ID`，不创建半成品任务；
6. 招商线索请求返回 `UNSUPPORTED_SCOPE`；
7. 不允许自然语言直接确认主体、确认/驳回证据、调整风险分或生成正式报告。

模型后续可以替换“意图和参数候选提取”部分，但模型输出必须经过相同结构化校验，不能改变上述门禁。

## 6. 建议动作映射

| `next_action` | 对话返回动作 |
|---|---|
| `EXECUTE_TASK` | 继续执行任务 |
| `CONFIRM_SUBJECT` | 打开主体确认 |
| `REVIEW_EVIDENCE` | 打开待核验证据 |
| `CALCULATE_RISK` | 计算风险分 |
| `CONFIRM_REVIEW` | 确认运营研判 |
| `GENERATE_REPORT` | 生成报告 |
| `RETRY_TASK` | 重试失败步骤 |
| `RETRY_REPORT` | 重试生成报告 |
| `DOWNLOAD_REPORT` | 下载最新已生成报告 |
| `WAIT/NONE` | 不返回可写操作 |

这里返回的只是前端动作描述，不会自动调用对应端点。

## 7. 自动化验证

已覆盖：

- 从中文风险调查指令提取完整企业名称；
- 从指令提取统一社会信用代码；
- 识别任务编号和任务 UUID 状态查询；
- 区分“招商线索任务”与名称包含“招商”的合法企业；
- 缺少企业或原报告时请求补充输入；
- 自然语言创建任务及重复请求幂等；
- 按任务 ID 和任务编号查询状态；
- 返回与工作台一致的 `EXECUTE_TASK` 建议；
- 明确拒绝当前范围外的招商线索；
- OpenAPI 契约可解析。

## 8. 当前边界与下一步

W10 是对话入口一期：

- 消息记录尚未持久化，刷新后由前端根据任务重新构建工作区，任务本身不会丢失；
- 暂未实现 `conversation_id`、多轮槽位自动继承和会话列表；
- 暂未接入外部模型，复杂口语、简称、多主体和上下文指代会要求用户补充；
- 暂不通过聊天文字执行证据决定、人工改分和正式报告生成。

下一阶段应增加会话与消息持久化、多轮任务上下文，以及前端对话页真实联调；随后再接入可替换的模型参数提取器，并用确定性解析器作为回退。
