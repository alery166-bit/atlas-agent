# W15 全新视觉与管理菜单重构记录

日期：2026-08-03

## 目标

解决运营端与 BidMind 等通用后台在“深色左侧栏、蓝绿色渐变、圆角卡片”上的视觉同质化，
同时将原先聚合在“能力与数据源”页面中的平台治理内容拆成可直接定位的管理入口。

## 视觉系统

- 采用“企业情报编辑台”方向：暖白纸面、黑曜文字、细线网格和朱红信号色；
- 移除固定深色侧栏，改为顶部业务导航与第二层管理导航；
- 业务页面使用报刊式标题、等宽索引、直角边框和明确的内容分栏；
- 冰川运营与墨玉政企仍可切换，但只改变纸面、文字和信号色，不改变页面结构；
- 桌面端保持高信息密度，窄屏下管理导航横向滚动，卡片和台账自动改单列。

## 信息架构

业务导航保留“发起研判、任务台、报告库”三个高频入口。管理台拆为七个独立入口：

| 菜单 | 路由 | 管理内容 |
|---|---|---|
| Skills | `/skills` | 主体查询、企业快照、公开信息、风险评分、报告生成能力登记 |
| 数据源 | `/data-sources` | ES、搜索引擎、联网模型检索、历史报告来源与失败边界 |
| 搜索与模型 | `/search-models` | Provider 路由、引用约束、意图模型及规则降级 |
| 规则评分 | `/risk-rules` | 风险区间、事件最低分、原始分与人工分留痕 |
| 报告模板 | `/report-templates` | DOCX V1、生成门禁、版本与差异、PDF 后置状态 |
| 运行监控 | `/operations` | API、企业数据、搜索、模型、评分、文档服务状态 |
| 审计日志 | `/audit` | 任务步骤、证据决定、评分调整、运营确认和报告版本范围 |

旧 `/capabilities` 地址保留，作为兼容入口展示 Skills 页面。

## 数据与安全边界

- 七个页面统一读取 `GET /api/runtime/capabilities`，不伪造已接入状态；
- ES 当前显示为 `ELASTICSEARCH / READY`，搜索 Provider 仍显示待配置，模型显示规则降级；
- 搜索密钥、模型密钥和 ES 认证不在浏览器读取或回显；
- 页面只提供运行状态与策略边界，生产敏感配置仍由服务器环境管理。
