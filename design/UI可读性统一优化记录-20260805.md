# UI 可读性统一优化记录（2026-08-05）

## 目标

面向运营人员长时间使用，统一平台字号、行高、控件高度和高密度页面布局，解决部分说明文字、
表格、审计和验收区域仅 7～10px、阅读费力的问题。

## 调整内容

- 建立统一字号层级：说明文字 12px、次要正文 13px、正文和控件 14px，主要正文 15px。
- 加深次要文字颜色，并统一行高、字体渲染和抗锯齿设置。
- 侧栏导航提升至 14px、42px 最小行高；页面标题提升至 22px，一级内容标题提升至 32px。
- 表格、台账、状态、版本、规则字段、连接器表单、模板和说明文字统一到可读字号。
- 运行监控和验收指标卡改为 `auto-fit` 自适应网格，避免为塞入固定列数压缩文字。
- 审计筛选改为四列自适应布局；高密度失败任务和逐样本验收表采用内部横向滚动，避免缩字。
- 输入框、下拉框和主要表单控件统一为至少 42px 高度。
- 保留冰川运营和墨玉政企两套主题，并分别提高次要文字对比度。
- 移动端同步调整侧栏、标题和筛选布局。

## 验证

- 前端生产构建成功，13 个路由全部生成。
- 运营端自动化测试 10/10 通过，新增统一字号与高密度布局回归检查。
- 已部署至 `http://10.210.0.62:8300/`，仅重建运营端容器；后端、PostgreSQL 和 ES 未改动。
- Chrome 实际复验：首页、规则评分、运行监控和验收评估均无页面级横向溢出。
- Chrome 控制台无错误或警告。
- 关键计算样式：导航 14px、页面标题 22px、正文说明 15px、字段与指标说明 12px、指标值 27px。
- 浏览器中低于 11px 的可见文字仅剩侧栏序号/字母图标，属于装饰性索引，不承担业务信息。
