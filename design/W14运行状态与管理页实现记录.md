# W14 运行状态与管理页实现记录

完成日期：2026-08-03

## 1. 目标

修复远端 Chrome 检查发现的三类问题：

1. 能力与数据源页仍展示离线 JSON/CSV、ES 待接入的过期静态说明；
2. 页面只有能力地图，没有当前实例的配置和管理边界；
3. Vinext 内部路由预取在每次页面切换时重复产生控制台错误。

## 2. 后端运行状态接口

新增只读接口：

```text
GET /api/runtime/capabilities
```

接口只返回脱敏后的运行状态，不返回 URL、用户名、密码、API Key 或其他密钥。返回范围包括：

- 企业数据 Provider 及运行模式；
- 搜索提供方名称、类型、是否配置、是否必需和引用能力；
- Agent 意图模型是否配置及规则降级状态；
- 风险引擎和规则版本；
- 报告格式和模板版本。

远端当前实测：

- 企业数据：`ELASTICSEARCH / ES_READ_ONLY / READY`；
- 搜索：`UNCONFIGURED / NOT_CONFIGURED`；
- 意图理解：`DETERMINISTIC_RULES / RULE_FALLBACK`；
- 风险评分：`atlas-risk-engine/1.0.0 / RISK_RULES_V1 / READY`；
- 报告：`DOCX_V1 / READY`。

## 3. 运营端调整

- 能力页标题改为“Agent 能力与运行配置”；
- 新增运行实例状态条，展示企业数据、搜索、意图理解和报告格式；
- 六项能力卡片全部根据后端实际状态渲染；
- 数据源矩阵区分“正常、待配置、检测中”等状态；
- 新增 Skills、数据源、搜索与模型、规则评分、报告模板、运行审计六类管理边界；
- 明确搜索、模型和 ES 密钥只由服务器环境管理，浏览器不读取、不回显；
- 任务和报告空状态显示当前运营人员，解释任务按操作人隔离；
- 所有内部导航关闭自动预取，消除 Vinext RSC prefetch 错误。

## 5. 边界

本轮实现的是配置注册表和运行状态展示，不提供浏览器端密钥编辑。真实搜索和联网模型接入后，
仍应通过服务器安全配置注入，页面会自动反映新的脱敏状态。
