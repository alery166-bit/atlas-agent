# W5 公开检索与证据链实现记录

## 1. 阶段结论

W5 第一条纵向链路已经完成：任务在冻结结构化企业快照后，可执行多 Provider 公开检索，对候选结果去重和主体匹配，经过运营确认后转换为风险事件，并调用现有评分引擎。必选搜索源失败会停止任务，同时保留完整失败批次。

当前结论是“离线契约与业务闭环通过”，不是“真实互联网搜索效果已验收”。

## 3. 关键防线

### 3.1 不把测试数据伪装成真实结果

测试 Provider 明确使用 `FIXTURE` 模式，并仅在 `test` profile 激活。非测试环境若没有真实 Provider，使用 `UnconfiguredPublicSearchProvider` 返回明确失败，不生成假舆情。

### 3.2 不把大模型摘要当证据

测试中增加无 URL、无引用的大模型线索。该结果进入 `LEAD`，提交确认时返回 `INVALID_PUBLIC_INTELLIGENCE_REQUEST`。

### 3.3 不把查询失败当作“未发现风险”

必选 Provider 失败时任务进入 `SOURCE_FAILED`。检索事务对该异常不回滚，因此失败码、失败信息和对应检索式仍可查询。
