## 1. 结论

V1 本地开发版本达到“可启动、可开发、可进行运营试走查”的技术交付状态。核心固定工作流、
离线企业数据、风险评分、公开证据、运营确认、DOCX、多轮会话和运营端均已闭环，并已
通过真实 Chrome 端到端自动化验收。

完成技术验证；统一身份、生产安全参数和业务黄金样本仍需取得真实环境/数据后验收。

## 3. 已满足范围

- 单企业风险排查与正式报告生成，新任务直接读取企业数据，不依赖历史报告；
- 原始分和人工分并存；
- 离线 JSON/CSV 开发数据；
- 查询失败立即停止；
- 风险等级及失联/欠薪/闭店最低分；
- V1 DOCX 模板、版本、差异、下载和哈希；
- 无普通/高级运营和审核角色；
- 冰川运营、墨玉政企主题；
- 一个 Agent 加多项受控能力，不拆多个独立 Agent；
- 对话入口、任务工作台、报告中心、能力/数据源、系统设置；
- 任务工作台受控操作闭环和 SSE 实时同步；
- 可选模型意图端口和低置信度/非法响应规则降级；
- 搜索重试、熔断、限流和低基数可观测指标；
- DOCX 上传防 Zip Slip、压缩炸弹和伪造文件；
- 同进程并发创建的幂等保护及数据库唯一约束；
- 可引用历史业务报告、人工最终版、企业 JSON 和运营决策的黄金样本框架；历史业务报告只作
  质量对照，不作为任务输入；
- 评分、证据、运营动作、报告结果、失败和终态耗时指标；
- Docker 构建和 Compose 定义。

## 4. 不能由开发环境替代确认的事项

| 事项 | 所需输入 | 验收方式 |
|---|---|---|
| 主流搜索引擎 | 服务商、接口地址、凭据、许可、限额 | 真实企业召回/误报/故障测试 |
| 联网模型 | 模型服务、凭据、引用格式、数据分级 | 引用可访问性与实体一致性测试 |
| 生产 ES | 版本、地址、索引、Mapping、认证、TLS | 离线/ES 同企业对照与性能测试 |
| 统一身份 | SSO/OIDC/网关方案和用户标识 | 登录、越权、审计和离职失效测试 |
| Docker 回滚演练 | 正式发布窗口和回退版本 | 应用回滚与迁移兼容测试 |
| 业务黄金样本 | 20～50 份历史业务报告及人工最终版 | 仅作漏报、误报、分值和版式回归，不作为任务输入 |
