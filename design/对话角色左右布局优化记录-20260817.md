# 对话角色左右布局优化记录

日期：2026-08-17

## 目标

将运营人员消息调整为右侧对话形态，使其与左侧的 Atlas Agent 消息在位置、头像、色彩和标识上能够快速区分，同时保持任务交付卡的完整宽度和移动端可读性。

## 实施结果

- 运营人员消息改为右对齐，头像位于消息右侧；普通指令采用内容自适应宽度，避免短指令占满整行。
- Atlas Agent 消息保留左对齐，头像位于消息左侧，并增加蓝色左侧识别线。
- 双方名称前增加稳定角色标识：运营人员为深色“指令”，Atlas Agent 为蓝色“AI”。
- 运营人员使用深色头像和浅蓝指令气泡；Atlas Agent 使用蓝色头像和白色结果卡，形成无需阅读名称即可辨识的视觉规则。
- 含任务卡的对话保持大宽度展示，避免进度、分数、证据数及报告操作被压缩。
- 移动端同步采用左右布局，并单独收敛头像、间距和气泡最大宽度。

## 验证

- 前端生产构建通过。
- ESLint 通过。
- 运营端页面契约测试 19 项全部通过，新增角色布局契约覆盖右侧头像、任务卡宽度和 Agent 左侧识别线。
- 已部署至 `10.210.0.62:8300`；前端和后端容器均正常运行，后端健康状态为 `UP`。
- Chrome 实际渲染复验：运营人员头像与气泡位于右侧，Atlas Agent 位于左侧；任务卡无横向溢出，页面无新增错误或警告。
