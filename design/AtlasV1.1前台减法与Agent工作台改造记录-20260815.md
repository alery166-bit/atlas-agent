# Atlas V1.1 前台减法与 Agent 工作台改造记录

日期：2026-08-15  
部署环境：`http://10.210.0.62:8300/`

## 一、改造目标

把原来“传统管理系统加对话框”的页面结构，调整为能够直接表达 Atlas 工作方式的运营前台：用户只负责下达目标，Agent 自主连续执行，只有无法可靠判断的异常才进入人工处理，完成后直接交付结论和正式报告。

## 二、信息架构调整

运营前台主导航收敛为四个入口：

1. `Atlas 工作台`：对话下达企业研判任务并接收结果。
2. `待处理`：只展示主体歧义、未核验证据和可重试失败等人工异常。
3. `任务记录`：保留全部历史任务、执行过程、证据、评分与报告详情。
4. `报告`：集中查看正式报告产物。

企业查询能力不再占用主导航，仍保留兼容路由，由 Atlas 在任务过程中自动调用；Skills、数据源、搜索与模型、规则评分、报告模板、运行监控、审计日志、验收评估和系统设置统一收进默认折叠的“系统管理”。

## 三、Agent 工作台调整

- 新任务首页明确说明“正常过程无需逐步点击，只有无法可靠判断的异常才会请你处理”。
- 删除对话消息下方重复的工作流操作按钮，避免让用户逐步驱动系统。
- 任务卡升级为四段式执行进度：主体与数据、公开信息、证据研判、评分与报告。
- 任务卡区分三种状态：`Atlas 自动执行中`、`需要你判断`、`Atlas 已完成`。
- 自动执行中的任务每 3 秒更新状态；进入完成态或异常人工态后停止轮询。
- 完成卡直接展示风险结论、风险分、公开证据数量和正式报告下载入口。
- 异常卡只提供“处理异常”入口，并跳转到带任务定位参数的待处理页面。

## 四、视觉调整

- 冰川风格升级为明亮科技蓝，采用浅灰白底、深蓝正文与电光蓝关键状态。
- 增强主标题、任务结论、执行进度和报告按钮的视觉层级。
- 减少边框噪声和重复卡片，系统管理改为树状折叠菜单。
- 继续保留墨玉政企风格切换，用户原有主题偏好不会丢失。
- 对桌面端、1120px 中等宽度和 820px 移动宽度补充响应式布局。
