# Atlas 生产安全与数据出域基线

日期：2026-08-19  
状态：代码基线已建立，正式启用依赖统一身份网关、证书、生产 ES 凭据及业务合规批准。

## 1. 身份与权限

- 本地开发和自动化测试允许 `ATLAS_SECURITY_MODE=LOCAL`。
- 生产必须使用 `ATLAS_SECURITY_MODE=PROXY`，后端只信任持有共享密钥的身份网关。
- 网关向后端注入 `X-Atlas-Authenticated-User` 和 `X-Atlas-Roles`；浏览器提交的
  `X-Operator-Id` 会被后端覆盖，不能伪造审计操作人。
- `OPERATOR` 可执行企业查询、研判、证据处理和报告操作；`ADMIN` 才可访问
  `/api/platform/**` 与指标接口。
- `/actuator/health` 保持匿名，以供容器健康检查；其余业务接口在生产模式下拒绝匿名访问。
- 身份网关到后端必须使用受控内网和 TLS，且必须删除来自外部请求的全部
  `X-Atlas-*` 身份头后再注入可信值。

## 2. 密钥与网络

- Tavily、百炼、ES、PostgreSQL 和身份网关密钥只通过部署环境或密钥管理服务注入，
  不进入前端构建参数、Git、镜像层、任务事件和应用日志。
- 生产 PostgreSQL 和 ES 不映射公网端口；仅允许 Atlas 服务网络访问。
- 生产 ES 必须启用 API Key 或用户名密码鉴权，不复用当前 `es-dev` 中关闭安全功能的配置。
- 对外入口使用 HTTPS；后端端口不直接面向用户浏览器。
- 上线前运行 `scripts/production-preflight.ps1`，失败项必须清零。

## 3. 数据出域矩阵

| 接收方 | 发送内容 | 明确不发送 | 用途 | 当前保存位置 |
|---|---|---|---|---|
| Tavily | 企业全称、已确认简称/品牌与公开网页检索请求 | ES 原始整包、风险分、联系人、内部备注、报告文件 | 公开网页发现 | Atlas 保存返回标题、URL、摘要、抓取时间及受控正文快照；第三方保存周期待合同确认 |
| 阿里云百炼 | 意图文本；证据研判时发送企业名称、已确认别名、证据标题、最多 1200 字摘要和来源 URL | 企业完整工商档案、评分规则源代码、正式报告、数据库凭据 | 意图识别、证据相关性/风险类型辅助判断 | Atlas 保存模型版本、调用次数、Token 和结构化建议；第三方保存周期待合同确认 |
| 公开网页站点 | 目标证据 URL、固定 User-Agent | 内部任务信息、评分、报告和身份凭据 | 对已发现来源抓取可复核正文 | Atlas 保存正文快照和内容哈希 |

任何扩大发送字段、增加新模型/搜索供应商或把完整 ES 数据交给模型的变更，都必须重新走
数据出域审批。日志不得记录请求中的密钥和完整正文。

## 4. 容量、成本和幂等

- 新建任务必须使用稳定的 `Idempotency-Key`；同一业务请求重试必须复用原键。
- 搜索与模型并发由连接器限流和 `ATLAS_MODEL_REVIEW_CONCURRENCY` 控制。
- 每个模型任务保存调用次数、输入 Token、输出 Token 和总 Token；平台运维页和
  `atlas.model.tokens` 指标用于成本核算。
- 真实压测会产生 Tavily/百炼费用，需先确认目标并发、日任务量和费用上限；未批准前只执行
  本地并发、恢复和幂等自动化测试。
- 首次生产压测建议从 2 个并发、20 个任务开始，逐级升到批准目标；每级记录 P50/P95、
  技术失败、转人工比例、外部调用次数和 Token。

## 5. 备份、回滚和监控

- PostgreSQL、报告卷和配置卷继续使用已验证的 `backup-docker.sh` 与
  `restore-drill-docker.sh`；生产环境必须增加定时备份、异地副本和保留周期。
- ES 生产备份使用 Snapshot Repository；仓库位置、保留周期和恢复演练尚待生产 ES 确认。
- 应用发布前保留当前镜像摘要；数据库迁移只向前，回滚应用前核对旧镜像能否读取当前 schema。
- 告警至少覆盖：健康检查失败、任务停滞、必需数据源失败、搜索/模型熔断、非法 JSON、
  DOCX 失败、过期报告下载阻断、Token 异常增长和磁盘容量。

## 6. 上线前待确认

1. 统一身份产品、网关地址、用户标识字段和角色映射。

3. 生产 ES 地址、鉴权方式、证书和 Snapshot Repository。
4. Tavily、百炼的数据保存/训练条款、公开来源许可和业务批准人。
5. 目标并发、日任务量、单任务 Token/费用上限与告警接收人。
6. 生产备份周期、保留周期、RPO、RTO 和异地备份位置。

以上六项未确认前，可以继续作为受控试点运行，但不能标记为“生产就绪”。
