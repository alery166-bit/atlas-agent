# W4 正式 DOCX 模板执行契约

## 1. 模板基线

正式模板文件：

```text
北京简熹和食品有限公司_企业风险监测分析报告20260714.docx
```

模板 SHA-256：

```text
370050ab5e814e0f05a7698f49c57703cdca5cc1915a3acd006bda6b98ac80a4
```

运行时模板版本采用 `V1-370050ab5e81`。若模板内容变化，哈希和模板版本必须同步变化，不能继续冒用旧版本。

## 2. 渲染原则

采用 preserve-only 策略：以正式模板为母版，只替换有明确数据来源和定位规则的受控内容。未受控的样式、页眉页脚、目录域、图片、章节层级、页面设置和其他 OOXML 包部件保持原样。

W4 不重新排版整份报告，也不将模板转换为另一套自建版式。

## 3. 受控更新范围

| 内容 | 数据来源 | 更新方式 |
|---|---|---|
| 企业名称、统一社会信用代码、法定代表人、状态等基础信息 | 最新 `DataSnapshot.companyFacts` | 按模板表格标签定位并替换值 |
| 行业类型、所属行业 | 标准字段或结构化行业 JSON | 选择对应行业层级并转换为可读文本 |
| 曾用名等数组字段 | 标准字段 | 去除空数组表示，非空值使用中文分隔符 |
| 工商变更 | 最新 `DataSnapshot.companyChanges` | 重建明细行；无记录时生成结构化占位行 |
| 风险评分和等级 | 最新 `RiskScoreSnapshot` | 同时保留原始分、人工分及等级 |
| 已确认风险事实 | 冻结风险事件及确认事件 | 仅输出可追溯事件 |
| 报告日期和数据日期 | 本次生成上下文 | 使用明确日期，不依赖 Word 当前时间 |

## 4. 复用范围

W4 会解析并复用旧报告中暂时无法由可靠新数据刷新、但仍需保持报告完整性的章节，例如部分公开舆情结论和说明性内容。复用不等于重新确认；接口返回的解析结果和差异中保留旧报告日期，便于运营人员判断时效。

## 5. 禁止行为

- 不把未经证据核验的搜索文本写成确定风险事实；
- 不因显示需要自行重算或四舍五入已存储的聚合分值；
- 不删除模板中的页眉、页脚、目录、图片和分页设置；
- 不使用全局字符串替换破坏同名字段或 Word 域；
- 不覆盖历史成功报告文件；
- 不把 QA 用 PDF 当作 V1 正式交付格式。

## 6. 文件完整性

- 生成文件 MIME 类型固定为 DOCX；
- 文件落盘后计算 SHA-256 和字节数并写入报告版本；
- 下载接口返回相同内容哈希；
- 本地存储使用临时文件加原子移动，避免读取到半成品；
- 文件名包含企业名称、报告日期和版本号。

## 7. 视觉验收

每次模板或渲染规则发生实质变化后，至少完成：

1. OOXML 包可打开性与关键部件检查；
2. 文本检查：无原始 JSON、无 `[]`、无模板占位残留；
3. Word 导出 PDF；
4. 对所有页面逐页检查截断、溢出、重叠、异常分页、表格错位和页码；
5. 校验视觉检查未意外修改正式 DOCX 内容哈希。

模板含外部引用域时，QA 打开文档选择“不更新外部域”，避免外部状态污染可复现结果。
