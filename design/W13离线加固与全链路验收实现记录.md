# W13 离线加固与全链路验收实现记录

日期：2026-07-30

## 1. 目标与结论

W13 在不依赖生产 ES、真实搜索凭据、联网模型凭据和统一身份的前提下，补齐 V1 可离线
完成的可靠性、安全、可观测和全链路验收能力。

最终结果：

- 后端全量 62 项测试通过，0 失败、0 错误、0 跳过；
- 运营端代码规范检查、生产构建和 3 项静态契约测试通过；
- 真实 Chrome 全链路 1 项通过；
- 5 个合成评分黄金样本通过，真实历史样本可按清单引用接入；
- 搜索、Agent 意图、文件上传、并发幂等和业务指标均具备可测试边界。

本记录是开发环境技术结论，不替代真实外部服务和业务样本的生产验收。

## 2. 实现范围

### 2.1 评分与证据实时事件

- 新评分快照发布 `risk.score.calculated`；
- 人工调分发布 `risk.score.adjusted`；
- 证据确认或排除发布 `public.intelligence.evidence.decided`；
- 运营端 SSE 订阅这些事件并刷新任务、证据和评分状态；
- 重复读取或复用既有评分快照不重复发布“已计算”事件。

### 2.2 真实浏览器全链路

`console/tests/operator-flow.e2e.mjs` 使用本机 Chrome 完成：

1. 上传真实 V1 DOCX；
2. 在对话框创建单企业旧报告更新任务；
3. 进入任务工作台并连续执行固定工作流；
4. 逐条确认或排除公开证据；
5. 计算原始风险分；
6. 保存人工分和调整原因；
7. 提交运营确认；
8. 生成并下载新版 DOCX；
9. 校验下载文件 ZIP 签名和最小文件大小；
10. 截图并切换冰川运营、墨玉政企主题。

`scripts/w13-console-e2e.ps1` 负责打包后端、构建前端、启动隔离 H2 实例和 fixture
搜索服务、运行浏览器用例以及清理进程。浏览器动作完成判断以实际 POST 响应和按钮恢复
为准，不依赖任务时间戳必然变化。

### 2.3 Agent 模型意图端口与规则降级

- 新增可选 `AgentIntentModel` 端口；
- 模型响应必须符合 `agent-intent.v1`、允许的意图、字段长度和必填项；
- 置信度低于 `0.70`、非法 Schema、非法意图、缺字段、异常或超时均回退到确定性规则；
- 明确的不支持范围、任务上下文和任务引用优先由规则处理；
- 模型不能跳过固定工作流、证据门禁、评分或运营确认。

当前没有配置真实模型实现时，系统完全使用确定性规则，行为与离线开发要求一致。

### 2.4 搜索韧性

每个搜索 Provider 独立支持：

- 连接超时、请求超时和最小调用间隔；
- 对 HTTP 429、HTTP 5xx、超时和网络 I/O 失败进行有界重试；
- 线性退避；
- 连续失败开路、开路窗口和半开单探针；
- 必选来源失败后停止任务，不进入评分；
- 请求、耗时、结果数、上游调用、重试、熔断状态和开路次数指标。

搜索指标只包含 Provider 名、受控结果和状态，不记录查询词、企业名、URL 或凭据。

### 2.5 黄金样本回归

`data/golden/seed-risk-cases.json` 当前包含 5 个合成基线：

- 无事件低风险；
- 失联最低 6 分；
- 欠薪最低 6 分且保留更高旧规则分；
- 闭店最低 8 分；
- 多个最低分事件取最大值而非相加。

框架校验 Schema 版本、样本 ID、源文件引用、原始分、风险等级、命中规则、确定性哈希和
规则版本。清单支持引用旧报告、人工最终版、企业 JSON 和运营决策，不复制跨任务产物。

真实 20～50 份历史样本到位后，只需按 `data/golden/README.md` 登记引用并补充预期结果，
即可进入同一回归命令。

### 2.6 安全与并发

- DOCX 上传同时限制压缩文件 20 MB、展开后 50 MB 和 2048 个条目；
- 实际解析 ZIP，拒绝伪造 PK 头、畸形包和危险条目路径；
- 要求存在 `[Content_Types].xml` 与 `word/document.xml`；
- 证据正文抓取默认拒绝私网、本机和重定向跟随；
- 会话和任务接口保留运营人员隔离测试；
- 同一幂等键的同进程并发创建使用键级锁和独立事务提交；
- 数据库唯一约束继续作为跨实例最终防线；
- 12 路虚拟线程并发创建测试只生成一条任务和一条初始状态事件。

### 2.7 业务可观测性

新增低基数 Micrometer 指标：

- `atlas.business.events`
- `atlas.business.task.status.transitions`
- `atlas.business.task.terminal.duration`
- `atlas.business.operator.actions`
- `atlas.business.evidence.decisions`
- `atlas.business.risk.scores`
- `atlas.business.reports`
- `atlas.business.workflow.failures`

指标标签不包含任务 ID、企业名、运营人员 ID、联系方式或正文。

## 4. 下一阶段真实验收门槛

以下事项必须等待真实输入，不应以 fixture 或合成样本替代：

6. 可运行 Docker Compose 的目标机（已于 2026-08-03 提供并完成体验部署）。

接入顺序建议：真实黄金样本与搜索服务可先并行；随后接联网模型；生产 ES、统一身份和
Docker 备份恢复/回滚演练在生产条件明确后进入。
